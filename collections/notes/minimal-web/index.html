搭一个很小的网站

2026.07.21 · 4 min read

个人网站不一定要复杂。它可以只是一个安静的地方，用来放下文字、代码和以后还想再看的链接。这里是一篇 文章页面 的排版示例。

先决定放什么

我通常把内容分成几个很小的部分：

  • 文字
    • 完整的文章
    • 还没长大的片段
      • 一句话
      • 一个待验证的想法
  • 代码与实验
  • 视频和外部链接

目录不需要一次设计好。先让它能够自然增加，必要时再把一个文件夹拆成更多层。

一小段代码

这个网站用 localStorage 记住主题。最核心的逻辑只有几行：

const key = "lilykekerun-theme";
const root = document.documentElement;

function setTheme(theme) {
  root.dataset.theme = theme;
  localStorage.setItem(key, theme);
}

颜色统一放在 CSS 变量中，因此深浅模式只需要替换变量值，文章本身完全不用改变。
